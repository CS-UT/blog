# بلاگ انجمن علمی علوم کامپیوتر دانشگاه تهران

این مخزن شامل کد منبع وب‌سایت بلاگ انجمن علمی علوم کامپیوتر دانشگاه تهران است که با استفاده از [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) ساخته شده است.

## راه‌اندازی محلی

### پیش‌نیازها

- Python 3.13 یا بالاتر
- [uv](https://docs.astral.sh/uv/) (پیشنهادی) یا pip

### نصب و اجرا

با استفاده از uv:

```bash
uv sync
uv run mkdocs serve
```

یا با استفاده از pip:

```bash
pip install -r requirements.txt
mkdocs serve
```

سپس به آدرس `http://127.0.0.1:8000` بروید.

## افزودن پست بلاگ

برای افزودن یک پست جدید به بلاگ:

1. یک فایل Markdown در پوشه `docs/blog/posts/` ایجاد کنید.
2. نام فایل می‌تواند هر چیزی باشد (مثلاً `اولین-پست.md`)
3. محتوای فایل باید شامل frontmatter با عنوان، تاریخ و نویسنده باشد:

```markdown
---
title: عنوان پست شما
date: 2025-01-15
authors:
  - نام نویسنده
categories:
  - آموزش
tags:
  - برچسب۱
  - برچسب۲
---

# عنوان پست شما

محتوای پست شما اینجا قرار می‌گیرد...

می‌توانید از Markdown استفاده کنید.
```

4. پست شما به صورت خودکار در صفحه بلاگ (`/blog/`) نمایش داده می‌شود.

### نکات

- پست‌ها باید در پوشه `docs/blog/posts/` قرار بگیرند
- پلاگین blog به صورت خودکار پست‌ها را بر اساس تاریخ مرتب می‌کند
- URL پست‌ها به صورت `blog/YYYY/MM/DD/title/` ساخته می‌شود
- دسته‌بندی‌های مجاز: `آموزش`، `اخبار`، `پروژه`، `مسابقه`

## افزودن نویسنده

برای افزودن نویسنده جدید، آن را به فایل `docs/.authors.yml` اضافه کنید:

```yaml
authors:
  نام نویسنده:
    name: نام نویسنده
    description: توضیحات
    avatar: URL تصویر (اختیاری)
```

سپس در frontmatter پست از `authors: [نام نویسنده]` استفاده کنید.

## افزودن مقاله

مقالات آموزشی را می‌توانید در پوشه `docs/articles/` اضافه کنید. برای هر مقاله یک پوشه جداگانه ایجاد کنید و فایل `index.md` را در آن قرار دهید.

## ساختار پروژه

```
blog/
├── docs/
│   ├── index.md              # صفحه اصلی
│   ├── .authors.yml          # اطلاعات نویسندگان
│   ├── tags.md               # صفحه برچسب‌ها
│   ├── blog/
│   │   ├── index.md          # صفحه بلاگ
│   │   └── posts/            # پست‌های بلاگ
│   ├── articles/             # مقالات آموزشی
│   ├── images/               # تصاویر سایت
│   ├── fonts/                # فونت‌ها
│   ├── stylesheets/          # استایل‌های سفارشی
│   └── javascripts/          # اسکریپت‌های سفارشی
├── mkdocs.yml                # تنظیمات MkDocs
├── pyproject.toml            # وابستگی‌های پروژه
├── requirements.txt          # وابستگی‌ها برای pip
└── CNAME                     # دامنه سفارشی
```

## قابلیت‌ها

این پروژه از قابلیت‌های زیر MkDocs Material استفاده می‌کند:

- پشتیبانی کامل از زبان فارسی و RTL
- حالت تاریک/روشن
- جستجوی متن کامل
- بلاگ با پشتیبانی از نویسندگان و دسته‌بندی‌ها
- برچسب‌گذاری
- کپی کد با یک کلیک
- نمودارهای Mermaid
- فرمول‌های ریاضی با MathJax
- و بسیاری امکانات دیگر...
